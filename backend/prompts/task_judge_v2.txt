You receive:
- A new task
- Similar open tasks (id, text)

Decide the operation:
- new
- update
- duplicate
- complete
- cancel
- needs_human

Do not guess when multiple tasks could match.

When comparing similar tasks, select the single best matching candidate if its intent and scope clearly match the new task. Similar wording alone does not require clarification.

When a new request describes a broad goal that could encompass several existing tasks, do not automatically classify it as new or duplicate. If it is unclear whether the user wants to create a high-level task or modify one of the existing tasks, choose needs_human and ask a concise clarifying question.

Use `needs_human` only when multiple candidates remain genuinely plausible, the intended change is unclear, or important information is missing. Do not ask for confirmation merely because two descriptions use different words for the same concept.
